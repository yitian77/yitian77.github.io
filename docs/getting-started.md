# 快速开始

本页面面向第一次接触 BlockZ 的玩家、整合包作者与服务器管理者，帮助你快速理解这个模组的玩法重心、推荐搭配与最重要的控制点。

## 运行环境

- **游戏版本**：Minecraft 1.20.1
- **加载器**：Forge 47.4.15
- **Java**：17
- **主要依赖**：GeckoLib、Curios
- **重点联动**：TaCZ、Thirst

## BlockZ 的玩法重心

- 资源携带受到更严格的容量限制。
- 装备选择会直接改变你能带多少物资。
- 受伤、骨折、失血、体力消耗会影响行动节奏。
- 探头、越肩视角和趴下等机制让战斗更偏战术化。

## 理解 BlockZ 的关键前提

在 BlockZ 中，**背包不是无限扩容容器**，而是和衣服、背心、附加装备槽共同组成的空间系统。

你需要把它理解成“装备决定可携带能力”，而不是“打开背包后默认拥有几十个格子”。

## 第一次进入世界时

1. 按 `E` 打开自定义 DayZ 风格背包界面。
2. 确认左侧附近物品区、中间角色区、右侧库存区的布局。
3. 注意你初始可用口袋数可能很少，具体由配置决定。
4. 优先寻找能提供容量的背包、背心、上衣和裤子。
5. 受伤后准备绷带、破布、夹板、吗啡或可待因等护理物品。

## 推荐搭配

- **TaCZ**：用于现代枪械战斗，BlockZ 已围绕其第一人称与弹药逻辑做兼容。
- **Curios**：用于扩展装备槽，并接入 BlockZ 的 DayZ 风格装备布局。
- **Thirst**：用于补足饮水 / 生存压力，BlockZ HUD 已预留适配方向。
- **JEI**：用于查看物品来源与配方，尤其适合整合包环境。

## 常用命令

以下命令来自项目当前源码中的真实注册内容。

| 命令 | 用途 | 说明 |
| --- | --- | --- |
| `/blockz reload` | 重载 BlockZ 配置 | 由主类注册，用于重载配置并广播服务端配置快照。 |
| `/blockz_reload` | 重载网格规则 | 用于重新加载物品占格与容量规则并同步给客户端。 |
| `/blockz_toggle_ui <true\|false> [target]` | 切换 DayZ UI | 按玩家粒度控制是否使用 DayZ 风格界面。 |
| `/blockz_grid_item <width> <height> [color]` | 修改主手物品占格 | 把主手物品写入网格规则，用于兼容其他模组物品。 |
| `/blockz_clothing_capacity <width> <height>` | 设置容量网格 | 为主手物品设置可用容量宽高，不再局限衣物。 |
| `/blockz_clear_corpse [targets]` | 清理尸体 | 用于测试或管理服务器世界中的尸体实体。 |

## 你应该先调哪些配置？

- `gui.ui.initial_pocket_slots`：决定开局口袋数量。
- `gui.ui.enable_dayz_inventory`：是否启用 DayZ 风格库存界面。
- `stamina.stamina.enable`：是否启用体力系统。
- `lean.lean.enable`：是否启用左右探头。
- `third_person_camera.enable_third_person_shoulder_camera`：是否启用越肩视角。

## 常见理解误区

- **不是所有容器都会被强制接管为 DayZ UI。** 项目已有菜单白名单策略以提高兼容性。
- **不是所有客户端都能随意使用本地配置覆盖服务端。** 多个关键参数采用服务端权威同步。
- **不是所有物品都默认适配多格尺寸。** 自定义规则通常通过 `grid_items.json` 维护。
